# About This Project - My Personal AI Chatbot

## What is This Project?

This project is my personal AI chatbot - a smart conversational assistant that knows everything about me (Abdullah Akram). You can ask me questions about my skills, projects, experience, education, or anything else, and I'll give you accurate, personalized answers based on my actual information.

This is NOT a generic chatbot. This is a RAG (Retrieval-Augmented Generation) system that uses my personal data to provide intelligent, contextual responses. When you ask a question, it searches through my portfolio, resume, and personal information to give you the most relevant answer.

## How This Chatbot Works (Technical Overview)
- My personal information is stored in text files (about me, skills, projects, education, etc.)
- These documents are split into smaller chunks (1000 characters with 200 overlap)
- Each chunk is converted into a 384-dimensional vector using sentence-transformers/all-MiniLM-L6-v2
- These vectors are stored in ChromaDB (a local vector database)

#### Step 2: When You Ask a Question
1. Your question is converted into a vector (same embedding model)
2. ChromaDB finds the most similar document chunks (semantic search)
3. The system checks if it's a personal question or general knowledge question
4. For personal questions: uses my stored data
5. For general questions: searches DuckDuckGo for web information
6. All context is combined and sent to the LLM (Qwen2.5-7B-Instruct)
7. The LLM generates a first-person response as if it were me

#### Step 3: Intelligent Caching
- The system has a two-level semantic cache
- Level 1: If your question is 85%+ similar to a previous question, it returns the cached answer instantly
- Level 2: Similar past Q&As are used as context for better consistency

## Key Features

### Semantic Understanding
Unlike keyword search, this system understands meaning. "What can you do?" and "What are your skills?" will return the same relevant information because they have similar semantic meaning.

### Multi-Source Context
The chatbot combines multiple information sources:
- Personal documents (about me, skills, projects, education)
- Previous similar Q&As from cache
- Web search results (for general knowledge)
- Conversation history (remembers context within a session)

### First-Person Responses
The LLM is instructed to respond AS me (Abdullah Akram), saying "I have built..." instead of "Abdullah has built...". This creates a more personal, engaging experience.

### Protected Personal Data
All my personal information is stored locally in text files and the ChromaDB database. The LLM doesn't store my data - it only uses it as context when generating responses.

## Technical Specifications

### Embedding Model
- Model: sentence-transformers/all-MiniLM-L6-v2
- Dimensions: 384
- Runs locally using PyTorch
- No API calls needed for embeddings

### Vector Database
- Database: ChromaDB
- Index: HNSW (Hierarchical Navigable Small World)
- Storage: Local disk (./chroma_db/)
- Search: Cosine similarity

### LLM
- Model: Qwen/Qwen2.5-7B-Instruct
- Provider: HuggingFace Inference API
- Cost: Free
- Context window: 128K tokens

### Caching
- Exact match threshold: 85% similarity
- Cache TTL: 7 days
- Max cache size: 1000 Q&A pairs

### Document Processing
- Chunk size: 1000 characters
- Chunk overlap: 200 characters
- Retriever K: 5 documents per query
