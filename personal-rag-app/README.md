# Personal RAG Chatbot

An AI-powered personal assistant using Retrieval-Augmented Generation (RAG) to answer questions about Abdullah Akram.

## Features
- 🔍 **RAG-powered responses** - Uses vector search to find relevant context
- 💬 **Streaming responses** - Real-time typing effect
- 🌙 **Dark/Light mode** - Toggle between themes
- 📱 **Mobile responsive** - Works on all devices
- 💾 **Conversation memory** - Maintains chat history

## Tech Stack
- **Backend**: FastAPI, LangChain, ChromaDB
- **Frontend**: React, Tailwind CSS
- **LLM**: HuggingFace Inference API (Qwen2.5-7B)
